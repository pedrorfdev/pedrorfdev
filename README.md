### 👋 Sobre mim

Desenvolvo aplicações web de ponta a ponta desde 2022: levanto os requisitos, modelo os dados, construo a API e a interface e publico. Mantenho em produção um sistema para uma clínica de terapia ocupacional e criei o [Vambora]([LINK-DO-VAMBORA]), que gera guias de viagem com a API do Gemini.

Sou formado em Análise e Desenvolvimento de Sistemas, pós-graduado em Ciência de Dados e IA e estou cursando a pós em Ethical Hacking e Cybersecurity. Gosto de entender o problema e o produto antes de escrever código.

### 🛠️ Tech stack

* **Front-end:** TypeScript · React · Tailwind CSS · Framer Motion · HTML · CSS
* **Back-end:** Node.js · NestJS · Express · APIs REST · JWT
* **Dados e infra:** PostgreSQL · MySQL · Redis · TypeORM · Drizzle · Docker
* **Aprofundando:** testes automatizados · CI/CD com GitHub Actions · design patterns em projetos maiores
